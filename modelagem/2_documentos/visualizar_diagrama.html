Modelo Lógico em Documentos

Estrutura mista: a coleção cursos agrupa a grade completa por semestres (1 leitura atômica sem JOIN) e a coleção disciplinas gerencia o catálogo e os arrays de dependências para análise via $graphLookup.

classDiagram
    class CursoDocument {
        +ObjectId _id
        +String codigo "01A"
        +String sigla "TADS"
        +String nome "Tecnologia em Análise e Desenvolvimento de Sistemas"
        +Integer ano_versao 2019
        +Integer ch_total_minima 2100
        +PeriodoGrade[] grade
    }

    class PeriodoGrade {
        +Integer periodo "1 a 6"
        +DisciplinaEmbutida[] disciplinas
    }

    class DisciplinaEmbutida {
        +String codigo "TAD0102"
        +String nome "Algoritmos e Programação"
        +Integer ch 90
        +Integer creditos 6
        +String tipo_vinculo "OBRIGATORIA"
    }

    class DisciplinaDocument {
        +String _id "TAD0009"
        +String codigo "TAD0009"
        +String nome "Programação Orientada a Objetos"
        +Integer ch 60
        +CursoVinculo[] cursos_vinculados
        +RequisitoItem[] requisitos
    }

    class CursoVinculo {
        +String curso_sigla "TADS"
        +Integer ano_matriz 2019
        +Integer periodo_ideal 2
    }

    class RequisitoItem {
        +String disciplina_codigo "TAD0102"
        +String nome "Algoritmos e Programação"
        +String tipo "E | OU"
    }

    CursoDocument *-- PeriodoGrade
    PeriodoGrade *-- DisciplinaEmbutida
    DisciplinaDocument *-- CursoVinculo
    DisciplinaDocument *-- RequisitoItem
