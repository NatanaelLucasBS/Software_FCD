PolyGrade — Modelagem Lógica Multiparadigma

Estrutura Curricular TADS 2019 — UFRN (Universidade Federal do Rio Grande do Norte)

Alterne entre as abas abaixo para inspecionar cada um dos três modelos lógicos desenvolvidos.

Paradigma Relacional — 3ª Forma Normal

Modelo Lógico Relacional (PostgreSQL 16)

Normalizado em 3FN para garantir integridade referencial forte via chaves estrangeiras. A resolução de matrizes é tratada via tabela associativa (MATRIZ_COMPONENTE) e os pré-requisitos via auto-relacionamento (PRE_REQUISITO) com operador booleano ('E' ou 'OU').

erDiagram
    CURSO ||--o{ ESTRUTURA_CURRICULAR : "1:N - oferta"
    ESTRUTURA_CURRICULAR ||--o{ MATRIZ_COMPONENTE : "1:N - estrutura"
    DISCIPLINA ||--o{ MATRIZ_COMPONENTE : "1:N - integra"
    DISCIPLINA ||--o{ PRE_REQUISITO : "1:N - exige (alvo)"
    DISCIPLINA ||--o{ PRE_REQUISITO : "1:N - e_requisito_de"

    CURSO {
        varchar(10) codigo PK "Código único (ex: '01A')"
        varchar(20) sigla UK "Sigla do curso (ex: 'TADS')"
        varchar(150) nome "Nome oficial completo"
        varchar(50) nivel "Graduação - Tecnológico"
        varchar(120) unidade "EAJ - UFRN"
        varchar(30) modalidade "Presencial"
    }

    ESTRUTURA_CURRICULAR {
        varchar(20) codigo_matriz PK "Ex: 'TADS2019'"
        varchar(10) curso_codigo FK "FK para CURSO"
        int ano_versao "2019"
        int ch_total_minima "2100"
        int ch_obrigatoria "1680"
        int ch_optativa "240"
        int ch_complementar "180"
        int duracao_semestres "6"
        boolean ativa "true"
    }

    DISCIPLINA {
        varchar(10) codigo PK "Ex: 'TAD0102'"
        varchar(150) nome "Algoritmos e Programação"
        int ch "90"
        int creditos "6"
        varchar(30) departamento "EAJ"
        text ementa "Lógica, vetores, modularização"
    }

    MATRIZ_COMPONENTE {
        int id PK "Identificador único"
        varchar(20) estrutura_codigo FK
        varchar(10) disciplina_codigo FK
        int periodo_ideal "1 a 6"
        varchar(30) tipo_vinculo "OBRIGATORIA"
    }

    PRE_REQUISITO {
        int id PK "Identificador único"
        varchar(10) disciplina_alvo_codigo FK
        varchar(10) disciplina_requisito_codigo FK
        varchar(5) operador_logico "E ou OU"
    }
Paradigma Documentos — Read-Optimized

Modelo Lógico Não Relacional em Documentos (MongoDB 7.0)

Estrutura mista otimizada: a coleção cursos embuti a grade completa por semestres (entrega a matriz inteira em 1 leitura atômica sem JOIN) e a coleção disciplinas gerencia o catálogo detalhado e o array de dependências para análise recursiva via $graphLookup.

classDiagram
    class CursoDocument {
        +ObjectId _id
        +String codigo "01A"
        +String sigla "TADS"
        +String nome "Tecnologia em Análise e Desenvolvimento de Sistemas"
        +Integer ano_versao 2019
        +Integer ch_total_minima 2100
        +PeriodoGrade[] grade
    }

    class PeriodoGrade {
        +Integer periodo "1 a 6"
        +DisciplinaEmbutida[] disciplinas
    }

    class DisciplinaEmbutida {
        +String codigo "TAD0102"
        +String nome "Algoritmos e Programação"
        +Integer ch 90
        +Integer creditos 6
        +String tipo_vinculo "OBRIGATORIA"
    }

    class DisciplinaDocument {
        +String _id "TAD0009"
        +String codigo "TAD0009"
        +String nome "Programação Orientada a Objetos"
        +Integer ch 60
        +CursoVinculo[] cursos_vinculados
        +RequisitoItem[] requisitos
    }

    class CursoVinculo {
        +String curso_sigla "TADS"
        +Integer ano_matriz 2019
        +Integer periodo_ideal 2
    }

    class RequisitoItem {
        +String disciplina_codigo "TAD0102"
        +String nome "Algoritmos e Programação"
        +String tipo "E | OU"
    }

    CursoDocument *-- PeriodoGrade
    PeriodoGrade *-- DisciplinaEmbutida
    DisciplinaDocument *-- CursoVinculo
    DisciplinaDocument *-- RequisitoItem
Paradigma Grafo — Index-Free Adjacency

Modelo Lógico Não Relacional em Grafo (Neo4j 5)

Mapeia a grade como um Grafo Direcionado Acíclico (DAG). Nós (:Curso), (:Estrutura) e (:Disciplina) são conectados por arestas direcionadas com propriedades. A navegação de pré-requisitos transitivos possui custo assintótico $O(1)$ por salto.
